# Mini Juego Hipo run

Implementación de juego tipo *infinite runner* desarrollado en Pygame; en el que debes esquivar los obstáculos de tortugas y murciélagos. 

La dificultad va aumentando progresivamente a medida que avanzas en el juego. 
Atrapa los huevos mágicos para obtener puntos extras y mini hipos al final de la partida.

## Instalación 

1. Clona este repositorio:
```
git clone https://github.com/Dafna-konig/Hipo-Run.git
```

2. Navega hasta la carpeta del proyecto:
```
cd Hipo-Run
```

3. Crea un entorno virtual y actívalo para descargar la librería Pygame evitando conflictos (ejecuta cada línea por separado).

    Para Windows:
    ```
    python -m venv venv
    venv\Scripts\activate
    ```
    Para Mac:
    ```
    python -m venv venv
    source venv/bin/activate
    ```

4. Instala Pygame 
```
pip install pygame
```

5. Corre el juego 
```
python hipo.py
```

## Cómo jugar

**Espacio:** saltar.

**Flecha hacia abajo:** agacharse.

**R:** reiniciar la partida después de perder.

¡Intenta conseguir la mayor cantidad de puntos y huevos mágicos posible!
